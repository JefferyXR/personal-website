Arduino
Game Device

Project Overview

  • Built a handheld device to train hand-eye coordination and short-term memory using an Arduino Nano, 3D-printed chassis and a custom PCB.
  • Soldered and arranged components with a focus on minimal internal clutter.
  • Programmed two game modes (Whack-a-Mole, Simon) using Arduino IDE.
  • Redesigned the chassis in Autodesk Inventor to improve ergonomics and usability.

Materials List

  • Arduino Nano V3.0 Atmega328p
  • 3D-printed white PLA chasis (100x100x35mm)
  • PCB board
  • Buzzer
  • Haptic motor
  • Potentiometer
  • On-off switch
  • 4 colour LED buttons
  • 9V battery
  • 2 clear Acrylic cutouts (100x100mm)
  • 16 small screws
